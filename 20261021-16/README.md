# Torsion Tea

A local React + Vite parametric STL studio for a one-piece, straight-torsion-bar thumb rocker. Hold the frame off a surface and gently roll its central paddle ±5°. The two integral square rods twist elastically. Unlike a leaf spring, spiral spring, bearing or snap hinge, the restoring element is a pair of straight axial torsion bars. No hardware, assembly, API key or server is needed.

## Imports and privacy

Pick files on desktop/phone or drop one file. All parsing, image decoding, CSG, preview and export happen in the browser; personal files are neither uploaded nor persisted. Samples under `public/samples` are original synthetic fixtures, generated by `create-fixtures.cjs`, with no third-party attribution required.

- PNG and JPEG, actual headers checked before decoding; 16 bytes–2 MB, ≤12 million pixels, ≤6,000 pixels per side. Source and converted-grid previews. Fit/contain or fill/crop with ±25% XY pan.
- Exact image method: composite transparency onto white, resample to a bounded 20×20 grid using browser canvas, calculate luminance 0.2126R + 0.7152G + 0.0722B. Threshold mode raises samples below threshold (1–254); relief mode maps darkness linearly to height. A triangulated continuous top heightfield has a closed side/bottom and a 0.4 mm backing. Relief depth is 0.4–3 mm. Backing overlaps paddle by 0.15 mm and is Boolean-unioned with it. This is **2D-to-relief conversion, not reconstruction of a full 3D object from one photo**.
- ASCII and binary STL: 40 bytes–2 MB, ≤1,500 triangles, 0.2–250 mm on each source axis. STL carries no units: a required checkbox explicitly confirms millimeter coordinates. Source preview and dimensions are shown. Only one convex, outward-wound, closed solid with broad flat Z-min bed contact (≥25% projected area) and no projected overhang is supported. Open, nonmanifold, inverted, degenerate, disconnected, self-intersecting, concave and overhanging meshes are rejected with guidance. No repair is claimed or performed. Unsupported models should be prepared in a mesh editor.
- Import footprint 4–7 mm (proportional XY), STL height 0.6–5 mm (independent Z), Z rotation ±180°, XY offsets ±1.5 / ±2 mm. Mesh centered automatically. A strict vertex-bounded safe rectangle confines the convex grip / image square inside the rigid paddle, leaving ≥4 mm to the rod root in X and ≥3 mm to paddle ends. Unsafe combined settings block export. Reset transformations, replace/remove import, reset image controls and return to built-ins are available.

## Parameters and solids

All lengths are millimeters, rotation degrees. Paddle width 18–26, fixed paddle length 22 and thickness 3; square torsion rod thickness 1–1.3, free length 12–18; paddle-end air clearance 4–8; frame wall 4, corner radius 2–4; outer grip grooves 0–0.5. The minimum remaining grooved frame wall is 3.5 mm. Defaults are width 22, rods 15×1.2×1.2, clearance 6, corners 4, grooves 0.3. Soft/Balanced/Firm presets and numeric plus slider controls are provided. Frame X = paddle width + 2×rod length + 8; Y = 22 + 2×clearance + 8. Exact exported XYZ bounds appear in the UI.

Manifold WASM robust Boolean operations fuse frame, rods, paddle and imported grip as **one** closed connected solid. Rod roots overlap by 0.2 mm before Boolean union. There are no interpenetrating exported shells or moving bearings to weld. The continuous rods retain the paddle; intended motion comes from deformation, not free rotation. Source files are constrained to maintain a support-free footprint. Generation runs in a worker with bounded resolution. Three.js supplies touch orbit, pinch/scroll zoom and fit view. Bundled npm dependencies include React, Vite, Three.js and manifold-3d; no CDN/runtime service dependencies.

Binary STL is generated directly from the same final vertices/triangles as the undeformed final preview. No motion simulation is claimed. Download names identify source type, paddle width and rod thickness. The single-part dropdown also exports the same solid individually.

## Printing / calibration

Print flat at Z=0, thumb relief upwards, no supports intended. Start with PETG, 0.4 mm nozzle, 0.16–0.2 mm layers, 3–4 walls, 30% infill; rods must resolve into solid continuous lines. PLA is usable for gentle trials but may fatigue sooner. Inspect sliced paths before printing. Remove by lifting the frame, clear brim/stringing from the air gaps without cutting rods, and hold off the table to allow downward travel. No assembly or release cut is required.

Use a built-in undecorated full-size print as the calibration trial. Begin gently below ±5° (paddle end travel about 1 mm). If too stiff, use 18 mm × 1 mm rods; otherwise adjust thickness in 0.05 mm steps. End clearance is configurable, not a universal FDM tolerance. Material, extrusion, layer adhesion and printer setup affect stiffness/fatigue. There is no hard stop; never force past ±5°, pull the paddle or bend the frame. Stop if whitening, cracking, permanent set or damage occurs. Broken rods can create small parts; not for young children.

## Validation

`npm run predeploy` builds the app. `npm test` checks defaults, extremes, 64 parameter corners, PNG-like threshold/relief fields and both STL sample imports. `TEST_BASE=http://127.0.0.1:5198 node browser-test.cjs` tests real file-picker imports/downloads, changed content/settings/transforms versus built-ins, malformed/truncated/oversized/unsupported files, reset/remove/replace, phone widths 320/390, touch orbit/pinch, export reachability, no remote requests, exact preview/export fingerprints and millimeter dimensions.

Export checks parse actual binary STL, verify finite nondegenerate triangles, stored normals, welded edge incidence exactly two/opposed directions, connectedness, positive enclosed volume and bounds. Manifold constructs valid solid unions. Geometry reports and browser reports are in JSON alongside screenshots. Mechanical checks cover 41 rigid paddle tilts from −5° to +5°, frame-end air clearance >3.5 mm, rod dimensions, connected retention and a conservative small-angle torsion shear proxy `thickness × angle / length < 1%`. Imports remain on the paddle and away from flexures; they cannot intersect the frame across that motion envelope. These are analytical geometry checks, not stress FEA or a fatigue model. **No physical print, durability or measured feel test has been performed.**
