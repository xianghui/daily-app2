# Dwell & Drive

Dwell & Drive: turn a partial-tooth spur wheel to counter-turn an output wheel during engagement; continue into the toothless interval for independent free motion, then gently align the teeth and reverse. This is NOT a locked-dwell Geneva mechanism: the output is free when disengaged. Three PLA/PETG parts, no hardware or supports intended. All parts export flat Z=0 with posts and hubs upward. Print at 0.16–0.20 mm layers, 0.4 mm nozzle, three walls, 25–35% infill. Deburr bores and elephant foot. Place each wheel on a separate post with hubs up; hand-hold level because both wheels are intentionally non-captive and lift off. Do not force re-entry if output was moved independently: lift output, align a gap with the entering tooth and reseat. Preview output follows an aligned ideal counter-turn over a hand-guided ±90-degree window and remains still outside it; tooth contact covers only part of that window. The stationary preview interval is illustrative, NOT a lock or dynamics simulation. Running clearance 0.3–0.5 mm per side and tooth-flank allowance clearance/4 are starting points, not universal tolerances. Open Sweep is a full-size calibration trial; verify a free bore and gentle mesh before making more. Minimum tooth tip is checked computationally; rigid teeth must not flex. No compliant parts. Personalization unions or engraves only within the isolated palm well, outside all gear sweeps. Images are bounded 20×20 sampled 2D-to-relief, not full 3D reconstruction. STL sources must be one closed outward convex flat-bottom solid, unsupported concavities are rejected, never replaced by a hull. STL has no units or colors; slice in millimeters at 100%. ZIP is three STLs and assembly notes, not 3MF. Computational mesh and representative collision checks are not physical print tests. Physical print, friction, re-engagement force, wear and fatigue have NOT been tested. Small loose parts: not for children.

## Run and dependencies

`npm install`, `npm run dev`; `npm run predeploy` builds with React + Vite. Local dependencies: Three.js / OrbitControls, Manifold WASM (Apache 2.0), fflate, Fredoka and Rubik through Fontsource (OFL). No CDN, API key or runtime service. Synthetic fixtures in `public/samples` are generated project artwork and simple solids, not personal files.

## Inputs and local processing

File picker and drag/drop accept PNG/JPEG, restricted simple SVG, and binary/ASCII STL. Files stay in browser memory. 2 MB/file, PNG/JPEG ≤12 million pixels and ≤6,000 px per axis; normalized to ≤500 px before sampling. SVG permits ≤2,000 simple filled shapes, no scripts, fonts, external references or effects, and rasterizes locally to 256 px. Holes in SVG fills remain background in the sampled relief.

Images sample a 20×20 grayscale height field. Threshold mode maps dark samples to relief depth; grayscale mode maps inverse luminance continuously. A continuous solid backing supports every sample; light holes remain unraised, not through-holes. Triangulated interpolation is intentional, not exact vector tracing. Background inversion, contain/cover, crop ±25%, threshold 1–254, raised depth 0.4–3 mm, engraving 0.4–0.6 mm, rotation and placement all affect the exported solid. Checkerboard shows the sampled cutout. This is 2D-to-relief conversion, not single-photo 3D reconstruction.

STL supports ≤1,500 triangles and source extents 0.2–250 mm per axis. Strict parser checks finite coordinates, dimensions, degeneracy, oriented welded edges, one connected component, positive volume, self-intersections, convexity and broad flat base. Concave, hollow, branched, open and nonmanifold meshes are explicitly unsupported, never silently repaired or replaced by convex hull. Select Z/Y/−Z up before import. Confirm millimeter source scale explicitly: STL stores no units. XY scales proportionally to 4–7 mm footprint; Z scales independently to 0.6–5 mm grip height. Z rotation ±180°, X ±1.5 mm, Y ±2 mm. The original transformed mesh is boolean-unioned into the palm floor; connectedness and a 6.5 mm radial keep-out check block unsafe placement. Replace/remove/reset and return to built-in grip are available.

## Parameter bounds (millimeters unless noted)

Palm diameter 22–28; pitch radius 12–14; gear face 4–6; radial bore clearance 0.3–0.5; active teeth 4–6 whole positions; hub radius 5–6; palm dimple depth 0–0.6. Shapes: round, hexagonal, oval. Three presets and bounded variations. Reference tooth profile: 16 positions, 20° involute; radial root clearance and per-flank allowance preserve noninterference. No locked dwell is claimed.

## State, views and exports

A debounced worker owns solid generation, CSG and final topology checks. Sequence IDs reject stale results. Invalid edits, pending conversion, bad imports, missing assets and worker errors disable export; the last valid preview is labelled if retained. Preview and export share exact validated buffers. Fingerprint in stage DOM enables independent download comparison. Print plate, assembly, exploded and isolated views use the same parts; assembly pose is illustrative only and is not exported.

Undo/redo, up to six named local designs, portable JSON save/open include bounded source image or mesh payloads. Missing image payloads explicitly request reattachment. Theme preference is local. STL exports include per-part buttons and separated full plate; Everything ZIP contains the three binary STLs and assembly notes. STL is geometry only, not preview colors. All exports are bed-flat, outward closed solids.

## Reproducible validation

`npm test` checks default, three presets, 64 parameter extrema and 35 imported-output cases. `node browser-test.cjs`, `node feature-test.cjs`, `node resilience-test.cjs`, `node stale-import-test.cjs`, `node hole-test.cjs` and `node motion-test.cjs` target the actual production output through `node serve-production.cjs`. Reports record actual completed results, not a physical print certification. Independent binary checks verify byte count, triangle normals, finite coordinates, nondegenerate faces, 1e-5 mm welded edge incidence/winding, connected-component positive volume and expected bounds. Manifold intersections check representative full turns, toothless free-wheel positions, vertical lift-off and plate separation. These checks do not prove real re-entry force, wear, friction or printer fit. No physical prints have been performed.
