# Plumb & Plane — computational validation

No physical print, accuracy, swing, friction, strength or material testing was performed. Fit/material calibration, supplied thread and adhesive remain required. Eye-lip contact shifts the real effective pivot from the idealized preview.

## Reproducible checks

- `npm test` → `geometry-validation.json`: **24** accepted built-in/preset/extreme cases and **35** image/STL-derived cases. Six oversized card combinations rejected clearly; invalid values, NaN transforms, unconfirmed units, empty relief and truncated files rejected.
- Independent binary float32 STL parser: exact byte length/count, nonempty finite nondegenerate triangles, matching unit normals, mm envelope, bed Z=0, welded edge incidence 2 with opposite winding (1e-5 mm), positive volume per edge-connected component. One component for every separate printable part and for the real connected card. All five exports checked per case.
- Independent Manifold assembly tests: pairwise seated intersections below 0.001 mm³ numerical tolerance; 7–11 vertical insertion samples from 0–25 mm; shoulder-stop overtravel; grounded feet/baseline; through bores including the raised stand-off. **25 bob poses at 5° increments across ±60°** clear board, feet and desk. Tick positions match intended angles and radius. All sixteen snips miss functional parts, and produce four distinct pieces plus one connected carrier. Card stays within its declared XY envelope; total Z ≤ sheet + 3.1 mm.
- A first extreme sweep detected bob/foot collision. Final geometry shortens feet to 10 mm height and moves joints to ±40% board width; all accepted cases rerun. A real 3 mm stand-off pivot boss was added to support the supplied thread in front of the board, and geometry/browser checks rerun.
- `node browser-test.cjs` → `browser-validation.json`: actual file-picker PNG/JPEG and ASCII/binary STL uploads, downloaded binary STLs, final-mesh parsing and independently regenerated portable JSON state. Every export fingerprint equals exact current preview geometry. Changed pixels/threshold/depth/crop/scale/rotation/placement change actual export; remove/reset restores default. Both STL formats, unconfirmed units, invalid dimensions, excessive file/pixel/triangle counts, bad topology, unsupported concavity, empty images, malformed files, invalid transforms and safe-zone violations checked with blocked export and recovery.
- Browser downloaded image/STL outputs run the same mesh and mechanical checks as built-ins. Phone file imports and actual downloads at 390 px; no overflow at 320/390 px. CDP touch orbit and pinch verified by canvas-image changes. No app runtime errors or remote generation requests.
- `node feature-test.cjs` → `feature-validation.json`: all three mesh-thumbnail presets, bounded variants, silhouettes, text/icon/SVG geometry, engraved and inverted relief; JSON with portable PNG/JPEG/STL, named persistence, undo/redo, dark-theme persistence, view modes, preview-only colours, drag/drop, Y-up STL, stale/current gating, sections/focus, real per-part STL buttons and real Everything ZIP. Unzipped all five STLs and parsed each.
- `node hole-test.cjs` → `hole-validation.json`: actual final-mesh probes confirm SVG ring's white center remains unraised/unengraved and dark ring changes solid geometry in both raised and engraved modes. Not a claim of a through-hole or exact vector tracing.
- `node resilience-test.cjs`: aborted production worker loading blocks export, reload restores; all six bundled icons generate different geometry.
- `node studio-layout-test.cjs`: 374 px left rail/right viewer, all isolated/exploded/flat views, view-neutral export, reduced motion, 320 px preview-first/no-overflow layout.
- `node pose-test.cjs`: bob-deflection preview visibly changes, board insertion pose usable, both remain geometry-neutral, actual flat card and assembled screenshots saved. Cord is explanatory only, not a printed part.
- Named imported PNG/STL designs after reload, invalid/missing portable payloads and delayed-old-image race: `named-import-test.cjs`, `portable-errors-test.cjs`, `stale-import-test.cjs`, matching JSON reports.
