# Flip & Cascade

A local **four-tile Jacob’s-ladder kit-card generator**, with a fifth removable threading shuttle. Three opposite-running soft ribbon lanes make a cascading flip toy. Tile width/height, lane pitch, face gap, grooves, sheet, card spacing and source-derived threading slots are real geometry controls—not a skin on a pinned rotor. Requires **three 4 mm woven ribbons and thin craft adhesive/tape**, not metal hardware.

## Local image / SVG / legend workflow

Choose or drag/drop PNG/JPEG/simple self-contained SVG; phone file pickers work. SVG accepts simple shapes/paths, ≤2,000 elements, rejects scripts/external references, and rasterizes locally to 256 px. PNG/JPEG signatures/dimensions are checked before decode: **16 bytes–2 MB, ≤12 MP, ≤6,000 px/side**. Sources normalize to ≤500 px for bounded portable storage, then sample a **20 × 20 grid**. Fit/cover crop, ±25% pan, light/dark background and threshold 1–254 or grayscale depth are supported. Text up to eight characters and six searchable marks use the same pipeline.

Each sample becomes a vertex height in a closed triangulated height-field tool; Manifold Boolean-subtracts it from tile-1. This is **2D-to-engraved relief**, not full 3D reconstruction or exact vector tracing. Bright holes remain uncut on continuous backing; final solid probes test this. Checkerboard displays the actual thresholded foreground, not the original rectangular image. Footprint 4–7 mm, Z rotation ±180°, X±1.5/Y±2 mm placement and **.4–.6 mm engraving depth** alter export geometry. Raised style is deliberately unsupported: face bumps would interfere with folding. Artwork is restricted to a 6.5 mm-radius zone between ribbon lanes, with ≥1 mm structural backing. Fine sampled artwork may blur at common nozzle sizes; it is not a functional interface. Empty artwork or leaving the safe zone blocks export.

## Local STL integration

ASCII and binary `.stl`, ≤2 MB and **≤1,500 triangles**, .2–250 mm per source axis. Show actual source dimensions/triangle count/format, choose Z/Y/−Z up and explicitly confirm millimeter coordinates. Axis changes clear the source and request reattachment. Original vertices/triangles scale proportionally in XY to a 4–7 mm footprint and independently in Z to **.4–.6 mm engraving depth**; rotate/center/place controls are real.

The transformed, inverted original mesh is Boolean-subtracted as a **mesh-shaped cavity** in tile-1. It is never replaced by a convex hull or exported unchanged. This limited contract accepts one connected, outward-wound, closed **convex solid with a broad flat bottom and no footprint overhang**. The parser checks finite/complete facets, dimensions, nondegenerate faces, 1e-5 mm welded edge incidence/winding, connectivity, positive volume, triangle intersections, convexity and bed contact. Open/nonmanifold, hollow/concave, disconnected, excessive and unsupported meshes are rejected with actionable errors; no automatic repair claim. A bottom hull is used only to validate footprint containment, not to replace geometry.

Images and mesh sources show independent source and final-model previews. Replace/remove/reset transforms/reset all work. Undo/redo, six local named saves and versioned JSON contain bounded normalized pixels/original mesh payloads. Missing image payloads explicitly request reattachment; invalid saved meshes are revalidated. No personal files are written to the repository or sent off-device.

## Print / assembly / interaction

The app and ZIP contain numbered assembly steps. Print flat in PLA/PETG, .16–.20 mm layers, three walls, no supports intended. Check bed size; use clean individual parts if needed. Snip twenty accessible runners outside functional lanes/slots; smooth edges. First export tile-1 and shuttle as the calibration pair. Default .15 mm total slot allowance depends on printer/material, not a guaranteed fit.

Dry-stack four tiles. Three soft 4 mm ribbons run along the recessed lanes; center goes in the opposite direction from both outer tapes. Reverse front/back routing on each subsequent tile, wrapping tile ends. Bond **short anchor tails only**, never the free traveling spans. Optional slots accept anchoring tails using the shuttle; the free ribbon still wraps an edge. The shuttle is removed, not retained in the mechanism. The shuttle head has an open-edge gauge notch exactly as wide as the selected face gap; use it to size a temporary paper spacer. Use temporary tape and that spacer; trial-fold each added stage before final bonding. Cut length per lane is `ceil(8*tileHeight + 8*tileThickness + 3*gap + 40)` mm, including wrap and trimming allowance. Default: **three 319 mm strips**, .15–.25 mm thick. Trim only after a complete dry routing trial. No hardware-free substitute for ribbon is claimed; all printed parts are included, external ribbon/adhesive are explicitly required.

Hold the top tile and tip forward/back to exchange ribbon support for successive flips. Binding requires manual tension/routing adjustment; do not pull hard. The assembled preview illustrates **only first-hinge opening with the lower three tiles rigidly stacked**. Ribbon centerlines and gap are estimated; it is not a textile/tension/force/gravity simulation. STL exports never include preview ribbons or assembly offsets. No physical print, gravity-cascade, wear, fatigue, tension, bond-strength or assembly-force test was performed. Computational fit checks cannot guarantee tactile action or printing success. Adult craft: small parts and scissors.

## Verification

`VALIDATION.md` summarizes reproducible scripts and actual reports. Independent float32 STL parsing checks file length, finite coordinates, normals/winding, nondegenerate triangles, millimeter bounds, exactly two opposite-directed incident faces per welded edge and positive volume per connected component. Checks run on all presets, parameter extrema, independent bounds, image-derived and STL-derived models—not only defaults. Each clean part and connected card is checked separately. Manifold intersections check first-hinge opening, flat-part disjointness, twenty safe snips, all 24 source-derived threading openings and 24 dual-face ribbon envelopes. These are geometric assembly checks, not claims that ribbon forces/cascading were physically tested.
