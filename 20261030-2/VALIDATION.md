# Trace & Tally validation

All checks here are computational or browser interaction tests. **No physical print, rolling accuracy, bearing wear, fatigue, force or adhesive tests were performed.**

- Reference: freshly downloaded and parsed actual binary source STL; SHA-256, dimensions, 27 edge-adjacent components, defects, four measured sockets and three real cross-sections recorded in `reference-analysis.json`. Local switch/link candidates also parsed and rejected for sheet-kit use. No raw third-party source STL bundled.
- `validation-report.json`: 8 built-in cases (all three presets, minimum, maximum, three silhouettes), plus 8 source-derived cases (ASCII/binary STL with two transform sets, threshold/grayscale × raised/engraved images). Every card/part independently checked, along with full assembly.
- `extreme-validation.json`: 15 image/STL extreme and mixed-range cases, plus rejection of invalid dimensions/counts. Minimum backing >= .8 mm and minimum true polygonal radial clearance > .19 mm throughout supported range.
- Binary STL: exact length, finite coordinates, nondegenerate faces, normalized normals consistent with winding, expected mm bounds, per-component positive enclosed volume and welded edges with exactly two opposite-directed incident faces, welding tolerance 1e-5 mm.
- Assembly: free wheel rotation at 38 noncommensurate angles, no unintended intersections; axle and wheel insertion paths, sideways keeper insertion, real shoulder/head stops, positive wheel retention in both axial directions, nonoverlapping bed-flat parts. Independent exported-card bands show 9 separate bottom runners and 7 separate top runners. All sixteen snip volumes avoid functional parts; cutting gives four parts plus carrier. Wheel rim nubs must still be flush-trimmed and path-calibrated; clean wheel STL is preferable for accuracy.
- `hole-validation.json`: direct Boolean solid probes verify unraised and unengraved image holes, rather than inferring them from a screenshot.
- `browser-validation.json`: real production-dist PNG/JPEG/ASCII/binary file uploads and actual STL downloads, pixel/threshold/depth/crop/scale/rotate/place changes, source replacement/removal/reset, exact preview/export/portable-JSON reconstruction signatures, every per-part STL, malformed/truncated/open/nonmanifold/concave/oversize/bad-dimension sources, empty silhouettes and out-of-bounds/blank transforms. Checks include real 390 px touch orbit/pinch and PNG/STL downloads, plus 320 px overflow/reachable-export checks. No external file requests or runtime errors.
- `studio-validation.json`: all actual presets, silhouettes, text/icons/SVG, engraving, portable image/mesh JSON, local named save/reload, missing-payload rejection, undo/redo, actual ZIP contents (every contained STL parsed), all assembly/print/isolated views, saved dark theme, keyboard focus, collapsible sections, reduced-motion, 374 px desktop left controls, phone preview first, intentional production-worker abort and reload recovery.
- `supplemental-validation.json`: Y-up/upside-down synthetic STL round trips, rapid edits, invalid edit blocks last-good export, recovery.
- `variation-validation.json`: eight bounded random variations generated valid current meshes; ghost/exploded screenshots.
- `gallery-validation.json`: every inline script compiled with `new Function`; unique newest `area:stl` entry, correct folder, existing 274 entries unchanged; STL Generators remains first category.
- `root-stage-validation.json`: combined root HTML and all 275 app routes staged, new assets/samples match individual dist bytes. `gallery-browser-validation.json` checks actual gallery rendering and new combined production route.

Print guidance and numbered assembly are included in README and ZIP. The calibrated flat-neck/handle and keeper/axle joints require adhesive; numerical retention does not imply their friction fit is self-locking. A 192-sided wheel is not a smooth exact cylinder and printer shrinkage, play and slip limit distance accuracy.

Publication: root `npm run predeploy` staged 275 apps with zero failures/skips; root `npm run deploy` published the combined folder. GitHub Pages deployment completed successfully (recorded in `pages-deployment.json`). `public-validation.json` records HTTP 200, production worker/WASM success, public default/PNG/STL manifold downloads, distinct imported geometry and all 275 gallery cards with Trace & Tally newest. No runtime errors.
