# Validation — Bridge & Bend / 20261031-9

Computational and browser checks only. **No physical printing, assembly, bending strength, fatigue, force calibration or external slicer test.**

## Reproduce

```sh
npm install
npm test
npm run predeploy
node serve-validation.cjs
# In a second terminal in this folder:
node browser-test.cjs
node studio-test.cjs
node stale-test.cjs
node axis-test.cjs
node hole-check.mjs
node personalization-test.cjs
```

The server serves the production bundle at `http://127.0.0.1:5589/daily-app2/20261031-9/`, including worker/WASM and bundled fonts. No dev-only URL assumption. Requires installed Playwright Chromium (`npx playwright install chromium` if absent).
