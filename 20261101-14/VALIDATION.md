# Observed validation — Petal & Bowl

- App production build (`npm run predeploy`) passed. Dependencies, fonts, worker and WASM are bundled locally.
- `node validate.mjs`: **38** full model cases passed (three presets, three profiles, field extrema, combined extrema, ASCII/binary STL-derived and image threshold/grayscale-derived outputs). Every connected card and every de-tabbed part was independently parsed after float32 binary serialization. Closed opposite-directed two-face welded edges, finite/nondegenerate triangles, stored normal direction, componentwise positive volume and expected millimeter bounds passed. Eight-component loose print layout also passed.
- Every case independently checks 28 assembled part pairs, 150 collar-insertion pair samples, lower-petal insertion paths, 12 tongue/socket probes, separated packed parts, exact declared envelope and Z=sheet thickness, and 32 runner cuts releasing eight parts plus the carrier. Bed-flat cross-sections have no unsupported area beyond a .0001 mm numeric footprint expansion. These are geometry checks, not force/load tests.
- Image ring test: bright central hole retains the full floor top; dark ring actually removes material. Exact exported ring-derived kit and assembly checks passed. Mixed narrow-card / large-collar packing rejects and disables export; larger card recovers.
- `browser-test.cjs`: actual PNG, JPEG, ASCII STL and binary STL file-picker imports and actual downloaded STLs. Pixel content, threshold, depth, fit/crop, scale, rotation and placement alter bytes. Download fingerprints match the exact preview result and Node regeneration of the current downloaded JSON; each imported result rechecks part meshes and assembly. Replace/remove/reset restores the baseline. Malformed, truncated, open/nonmanifold, concave, excessive-byte/triangle/pixel/dimension files, empty artwork and invalid transforms reject recoverably with export disabled.
- `studio-test.cjs`: three actual preset downloads, profile changes, text/icons/SVG, portable image and original-triangle STL JSON, reloadable named designs, missing payload errors, undo/redo, real ZIP decompression and every contained STL, all views, theme persistence, keyboard focus, collapsibles, reduced motion and worker abort/recovery passed.
- `orientation-test.cjs`: Z / Y / −Z up, explicit mm confirmation, expected dimensions, exact final geometry and assembly passed.
- `rapid-test.cjs`: spacing changes export; fast edits and late worker replies cannot enable invalid export; reset fingerprint, background polarity, and each dedicated part-button download passed.
- `mobile-test.cjs` and main browser test: 320/390 px preview-first, all tabs, expanded instructions, no horizontal overflow, reachable JSON/STL exports, SVG/image/STL pickers and real CDP touch orbit/pinch passed. Desktop checked 374 px left controls and right viewer. Screenshots were visually inspected for real assembly, card connectivity and studio layout.
- Gallery: every inline script compiles with `new Function`, 345 entries render without runtime errors, new `stl` entry exactly once/newest first, all **344** earlier entries unchanged, STL Generators first. Existing tagline already describes the requested STL focus and was retained.
- Root predeploy: **345 built, 0 failed, 0 skipped**. Root index and every new-app production file byte-identical in deploy/. Combined-root production browser tests repeat all four import formats and actual geometry/assembly-checked downloads with the real worker/WASM paths.

Evidence: `reference-measurements.json`, `reference-analysis.json`, `geometry-validation.json`, `browser-validation.json`, `studio-validation.json`, `extra-validation.json`, `orientation-validation.json`, `rapid-validation.json`, `mobile-layout-validation.json`, `gallery-validation.json`, `root-deploy-validation.json`, `combined-browser-validation.json`, and screenshots under `evidence/`.
