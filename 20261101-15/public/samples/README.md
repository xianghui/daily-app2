# Local synthetic samples

Original synthetic test assets adapted from earlier daily studios, no private files or third-party STL reference redistributed. `mark.png` is high-contrast artwork, `waves.jpg` grayscale artwork, `ring.svg` has a real central bright/transparent hole. `wedge-ascii.stl` and `gem-binary.stl` are closed convex test cutters, not assembly components. Use Import, confirm millimeter units for STL, then download the changed card or vertex-hub-1. Files stay local.
