# Tow & Trace

An original six-part flat-pack **pursuit-curve drawing kit card**. Drag a captured shoe along a straight guide while a freely pivoting pencil arm trails. A constant tow length plus ideal no-side-slip at the pencil gives a tractrix; real hand-drawn curves depend on friction, play and technique. This is neither a motorized plotter nor a calibrated drafting instrument. No physical print, assembly or drawing tests have been performed.

## Image / text / SVG workflow

Picker (phones and desktop), drag-drop or local sample buttons: PNG/JPEG≤2MB,≤12MP/6,000px per side. Actual header/content checks precede decode. Downscale to≤500px portable PNG, then sample a20×20 grid with contain/cover and ±25%crop offset. Light or dark background compositing/inversion. Threshold1–254 or grayscale depth.4–.6mm gives a closed triangulated height-field cutter. Its exact solid is Boolean-subtracted in the **front guide patch** centered(0,-13), safe radius6.5. The flat base of the cutter terminates at the surface; bright holes have zero cut depth, preserving the underlying solid. This is **2D-to-relief/sampled silhouette conversion, not full3D reconstruction from one photograph** and not exact vector tracing. Use bold, high-contrast art; sub-nozzle details can be lost. No true through-holes or outline-shaped body promised.

Checkerboard shows actual converted transparency. Footprint4–7mm; rotation±180°; placement X±1.5,Y±2mm; invalid corners outside safe patch blocked. At least1mm backing remains and art never enters slot or foot joints. Only engraved style is offered deliberately so the arm's sliding plane stays clear. Text up to8characters and six searchable bundled filled SVG icons use the same real geometry pipeline. Simple filled SVG paths/shapes≤2,000elements,≤6,000px; reject scripts, external resources, references and effects, then rasterize locally to256px. Holes survive as uncut backing. Original source and final model previews; replace/remove/reset and background/threshold/depth changes affect exported STL, not preview textures.

## STL workflow

Both complete ASCII and binary STL≤2MB/1,500triangles, .2–250mm per source axis. Select Z/Y/−Z up before attaching, inspect actual source dimensions/preview, **confirm mm explicitly** (STL has no units). One outward-wound, positive-volume, watertight connected **convex**, broad-flat-bottom solid is supported. Parser checks finite coordinates, degenerate faces, welded1e-5mm edges/opposite winding, connectedness, volume, dimensions, self-intersections, convexity, bed contact≥25%footprint, and no overhang projection. Unsupported concavity/cavities/multi-body/open/nonmanifold geometry is rejected with re-export guidance. No repair or convex-hull substitution. A2D hull is computed ONLY to verify bottom contact, never to replace the source.

XY scales proportionally to4–7mm footprint, Z independently to.4–.6mm engraving depth; scale factors shown. Rotate and place within safe patch. Actual unchanged source mesh topology is used for Boolean subtraction, but the exported **guide is a new modified solid**, not a source re-export. Narrow final XY dimension<1.2mm rejected. Reset transform, replace/remove and defaults are usable after errors. Portable JSON restores mesh arrays and revalidates them; no missing-file pretending.
