# Rung & Helix

A local browser studio for a **seven-part laced double-helix kit card**, not a reskin of the preceding string drawing kit. Five rungs have differently angled real rectangular slots: they lower over one mast and are bonded at measured heights. Two external soft cords lace corresponding rung-end eyes. There is no moving joint, switch socket, or claimed DNA-accurate geometry.

## Run and build

Node22.12+; `npm install`, `npm run dev`, `npm test`, `npm run predeploy`. React/Vite, Three.js OrbitControls, Manifold WASM in a Web Worker, fflate, bundled Fredoka/Rubik OFL fonts. All dependencies/WASM/fonts served locally; no CDN or remote API. Base `/daily-app2/20261101-3/`; per-app gh-pages scripts are present, but monorepo publication must use ROOT predeploy/deploy.

## Local image and mesh workflows

File picker on desktop/phone and drag/drop: PNG,JPEG,simple SVG and ASCII/binary STL. Synthetic sample downloads and Try buttons require no personal files. Maximum2 MB; PNG/JPEG header checks before decode,<=12 MP and6000px side, normalized<=500px. SVG<=2000 simple elements, no scripts/external resources/text/effects; rasterized locally256px. SVG holes survive rasterization. Images are composited against a chosen light/dark background, fit/cover-cropped and shifted, then sampled20×20 luminance. Threshold silhouette or grayscale height field becomes a closed relief cutter with interpolated triangle heights, Boolean-subtracted into the protected base extension. Bright holes remain unengraved on continuous backing; this is sampled relief, NOT exact vector tracing or automatic full3D reconstruction. Source and exact sampled checkerboard cutout visible. Depth.4–.6 mm, footprint4–7 mm, rotation±180degrees, offsets X±1.5/Y±2mm, circular6.5mm safe zone. Empty art/out-of-zone edits block export; minimum backing>=1.4mm. Text up to8 chars and six searchable bundled SVG marks use the same real geometry pipeline. Engraved-only policy is explicit, not a fake raised option.

STL parser verifies<=1500 triangles,finite coordinates,nondegenerate faces,closed opposite-directed edge pairs after1e-5mm weld,one outward positive-volume component,self-intersections,dimensions .2–250mm per axis. **Supported input contract: convex, broad-flat-bottom, no overhang outside bed footprint. Concave/hollow/branched/open/multibody meshes are explicitly rejected, never hulled or silently repaired.** Set Z/Y/−Z up before attach; oriented source3D preview and millimeter dimensions shown; confirm mm explicitly. XY scale maps longest axis to4–7mm footprint, independent Z scale maps height to.4–.6mm cutter depth. Rotate/move/reset/replace/remove all alter actual Boolean engraving, not preview textures. This is a deliberately protected base integration, not wholesale imported base replacement; interfaces remain untouched.

Files stay in the browser, never uploaded or saved as personal repo assets. Portable JSON and up to6 local named designs store bounded source pixels/normalized PNG and mesh payloads (JSON<=2MB); restored meshes revalidated. Missing image payload requests reattachment and blocks export. Undo/redo stores up to35 states. Preview colours are cosmetic only; STL has neither colours nor units.

## View, export and printing

Orbit/zoom/fit and phone touch/pinch. Assembled, exploded, connected-card, de-tabbed layout and seven isolated-part views all use the same final solids. Assembly placement/expanded spacing are explanatory, not mechanical simulation. Translucent base available. Source and final previews remain distinct. Building/error status, stale-result ids/state keys and per-edit mesh preflight disable export after invalid edits; a last-good preview is explicitly labelled, never silently exported.

Prominent binary-STL download; per-part buttons and Everything ZIP include connected-card STL,seven clean part STLs and numbered ASSEMBLY.txt with current dimensions. Exports always bed-flat Z=0,irrespective of assembly view. Shared exact result/fingerprint links preview to export. No3MF claim.

Print100% mm,PLA/PETG,.16–.20mm layers,three walls,no supports intended. Trial-print base/mast/rung3 for calibration. Snip28 runners outside functional edges. Bond mast with shoulder at base top. Slide rung1–5 in order from mast top; first underside8mm above base,then selected9–12mm pitch. Each keyed rectangular slot also admits180degree reversal: mark corresponding ends before snipping and keep the continuous turn. Hold level with ruler/paper jig while bonding each seat; **six fixed adhesive seats and no integral height stops**. Lace two soft cords<=1mm through1.8mm eyes loosely, with vertical leads through holes and bends outside sheets. Do not pull taut or load rungs. Cord,ruler,paper jig and filament-compatible adhesive are external supplies. Cords are not shown in preview. See in-app/ZIP numbered guide for full sequence. Default25degree steps are a stylized helix, not chemical DNA pitch.
