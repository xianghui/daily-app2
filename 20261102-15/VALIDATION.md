# Validation — Log & Slide

Reference mesh parsed and cross-sectioned before final geometry; actual source hash, dimensions, components, defects and measured-to-proposed decisions recorded. Local candidates and Keycap Studio instructions inspected read-only.

- `npm run predeploy`: production Vite build, locally bundled worker/WASM/fonts, real base prefix.
- `npm test`: 32 default/preset/shape/individual endpoints/combined endpoints/image/STL cases; every separate STL, connected card and translated loose plate independently parsed for closed oriented welded edges, finite nondegenerate triangles, normals, positive per-component volume and bounds.
- Actual solid checks: six slide positions, 36 vertical insertion cases per model, floor support, side-gap inflation, eight accessible snip cutters, exactly three components after release, print spacing, support footprints, declared envelope, log tick equations and multiplication identities.
- `personalization-check.mjs`: bright center preserves backing, dark image ring creates real recessed voids.
- `browser-test.cjs`: actual production PNG/JPEG/ASCII/binary picker imports and binary STL downloads; preview fingerprint equals bytes and Node regeneration from portable JSON. Threshold/depth/crop/content and mesh scale/rotation/placement alter actual exported solids. Derived models run the same mesh/mechanism checks.
- Invalid/truncated/open/nonmanifold/concave/excess-size/pixel/triangle/dimension inputs, white silhouette, invalid numeric/transform states: recoverable errors and disabled export, replace/remove/reset tested.
- `studio-test.cjs`: every preset, silhouettes, text/icon/SVG, JSON/image/STL round trips, named reload, missing payload block, undo/redo, actual ZIP unpacking and every contained mesh, all views, saved dark theme, keyboard focus, collapsible sections, desktop left rail, worker-loading failure/recovery.
- Phone 320/390 px: preview first, all editor tabs and view states, expanded guide, reachable JSON/STL exports, PNG/JPEG/ASCII/binary imports, touch orbit/pinch, no overflow. Six icons, drag-drop, three up-axis orientations, stale-result immediate export gating and isolated views exercised in extra scripts.
- Root gallery: every inline script compiled by `new Function`, new STL entry exactly once/newest, all 374 pre-existing entries unchanged, rendered browser search and category order checked.

Reports and screenshots alongside scripts and under `evidence/`. Combined deploy byte equality and production-path imports are checked before root publishing.

**No physical printing, accuracy, legibility, fit/friction, breakaway force, material strength or durability was tested.** A watertight mesh and computed fit do not establish these outcomes.
