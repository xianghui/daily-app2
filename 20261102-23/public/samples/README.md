# Synthetic local import fixtures

mark.png, waves.jpg and ring.svg are synthetic contrast / hole marks made for studio import tests. wedge-ascii.stl and gem-binary.stl are original small convex flat-bottom solids, not third-party models. All are safe to use as examples; no private uploads or source reference meshes are included. PNG/JPEG pixels and threshold/depth changes must change the exported ONE-face recess. STL imports require millimeter confirmation and are subtracted as actual transformed solids.
