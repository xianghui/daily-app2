Reference analysis: create a Python environment with trimesh/numpy/matplotlib/scipy/networkx, download the documented reference outside the repo and run `reference-measure.py PATH_TO_STL`. Raw source mesh is deliberately not checked in.

**No physical print, friction, thread wear, retention under handling, structural or measurement-accuracy testing was performed.** Printer/material tolerances are starting points. This kit requires external M3 screw/washers/nylon locknut; included printed spacer doubles as a bore coupon. It is a sight-over-drawing demonstrator, not calibrated metrology.
