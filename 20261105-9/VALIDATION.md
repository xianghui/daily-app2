# Validation — Pinhole & Project

All results are computational/browser checks, **not physical printing, light sealing or optical performance tests**.

- Actual public source STL re-downloaded and parsed. SHA-256, units assumptions, 27 edge-adjacent components (including degenerate pseudo-components), source nonmanifold warning, source dimensions and real cross-sections recorded. Local MX/fabric candidates were also parsed and rejected as unrelated to a planar kit.
- `npm run predeploy` passed. Vite bundles local worker/WASM/fonts at the real `/daily-app2/20261105-9/` prefix.
- `node validate.mjs`: **59 cases passed**, covering defaults, all presets/shapes, each numeric endpoint, combined endpoints, 16 camera geometry corners, image threshold/grayscale, ASCII/binary STL and transformed source cases. Each serialized part and connected card: finite nondegenerate triangles, outward normals, positive component volumes, closed welded edges with exactly two opposite-directed faces, expected mm bounds. Clean plate: exactly three separate components.
- Each case additionally: correct card bounds; 12 real runner cuts produce exactly one carrier plus 3 unharmed released parts, no fragments; unobstructed pinhole, screen and blind tracks in both card and clean solids; support-free bed footprints; ≥4 mm protected art backing; full 47-position sliding stroke without collision, 329 screen insertion samples and 31 front insertion samples. Gravity seating is explicitly not positive retention.
- `node browser-test.cjs`: real file-picker uploads and downloaded STL for PNG/JPEG/ASCII/binary sources; changed pixels, threshold, depth, crop, scale and transforms produce changed exports. Each downloaded geometry hash matches the shown preview, portable JSON regenerates the exact same bytes, and its resulting parts/mechanism pass mesh/fit checks. Replace/remove/reset recover deterministically. Unsupported/malformed/truncated/open/nonmanifold/concave/excessive and empty inputs block export. Touch orbit/pinch and phone imports/downloads passed.
- `node feature-test.cjs`: every preset/shape, text/icon/SVG and background mode, asset-bearing JSON round trips, named local persistence, undo/redo, real ZIP contents and per-part STLs, assembled/exploded/card/plate/isolated views, saved dark theme, preview-colour neutrality, drag/drop, Y-up STL, collapsible sections, keyboard focus, rapid worker edits, invalid export blocking passed.
- `node resilience-test.cjs`: intentional production worker-script failure blocks export; reload recovers. All six original bundled SVG icons change actual geometry.
- `node portable-errors-test.cjs`: missing image payload explicitly requests reattachment; invalid transform, wrong app id and invalid dimensions are rejected; reset recovers.
- `node stale-import-test.cjs`: delayed older async image normalization cannot overwrite a newer selection.
- `node hole-test.cjs`: probes final Boolean solid from imported ring.svg; center hole preserves backing and dark ring removes actual material.
- `node mobile-layout.cjs`: 320 / 390 / 480 px, every editor tab and expanded instructions; viewport stays unscaled, no horizontal overflow, preview-first order, actual reachable JSON download. Desktop rail is 374 px left of viewer. Screenshots manually inspected.
- Root gallery: inline scripts compiled, new entry exactly once, STL category first, all **455 previous entries unchanged**, total **456**. Combined-production gallery rendering passed with zero runtime errors. All 26 downloaded-output cases, malformed-file recovery, PNG/JPEG/ASCII/binary imports and phone touch/import/export tests also passed again against the actual root deploy folder; see `combined-browser-validation.json` and `combined-gallery-validation.json`. Root predeploy reported **456 built, 0 failed, 0 skipped**, and all 456 gallery destinations exist.

Reports: `geometry-validation.json`, `browser-validation.json`, `feature-validation.json`, `resilience-validation.json`, `portable-errors-validation.json`, `stale-import-validation.json`, `hole-validation.json`, `mobile-layout-validation.json`, `validation-summary.json`, plus gallery reports. Reproduction instructions are in README.

Not tested: real FDM print, printer-specific fits or elephant foot, screen handling/wear, paper sleeve light leaks, actual projected image, visibility/brightness/sharpness. Optional foil pinhole is an external manual improvement, not a tested accessory. A coarse printed cylindrical pinhole can vignette. Screen is not captive; keep the assembly horizontal. Required tracing paper / opaque paper / tape are disclosed throughout.
