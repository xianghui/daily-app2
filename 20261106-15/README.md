# Signal Fold

A local-AI customer-research utility: turn repeated customer feedback into a reviewed, traceable theme backlog. Unlike exact-text deduplication, semantic embeddings can connect differently worded requests. No original records are deleted.

## Use

1. Paste 1–32 English feedback lines, or import a UTF-8 `.txt` (80 KB maximum file, 20,000 total characters, 500 characters per line). Two synthetic examples are included.
2. Set grouping strictness (default cosine 0.45). Explicitly click **Load AI & fold feedback**.
3. Review source snippets and similarity explanations, name themes, reassign records or **Keep separate / reject**. Undo reverses edits. Theme names are human-authored, not generated by a language model.
4. **Apply reviewed themes**, then download JSON/CSV or copy JSON. Every original line has a stable ID. Any edit invalidates the applied artifact until re-applied. Importing/changing source text cancels running work and resets review.

## Real AI and deterministic processing

- Model: [Xenova/all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2), quantized q8 ONNX, Apache-2.0; derived from [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2).
- Runtime: locally bundled `@huggingface/transformers` 4.3.2, ONNX Runtime Web, CPU/WASM single thread. No WebGPU needed. No external provider integration or API keys.
- Real neural inference produces normalized 384-dimensional vectors, batches of four, 256-token model cap. Input character caps reduce, but cannot universally eliminate, truncation for unusual tokens.
- Deterministic complete-link agglomeration merges the closest groups only if **every cross-pair** meets the selected threshold. The number of themes and lowercased exact-text-distinct baseline are computed, not accuracy or time-savings claims. Duplicate source rows remain independently represented.
- Result checks require correct vector count, dimension, finite values and unit norm; export validates all source IDs/texts and valid group ranges. Malformed model output is rejected, never replaced with fake results.

## Downloads, privacy, cache and device limits

First run needs internet: approximately 23 MB quantized weights plus 26.9 MB uncompressed bundled WASM and smaller runtime/tokenizer files. Model files download from Hugging Face and its CDN; same-origin JavaScript, worker, WASM and factory module are served by this app. Loading status shows model download progress followed by batch progress. Cancel terminates the worker; retry can reuse cached complete downloads. A 180-second deadline stops stalled loads/runs. No weights are shipped in Git.

Use a modern browser with JavaScript, module workers, WebAssembly, WASM SIMD and enough memory (desktop recommended; no universal phone-speed guarantee). CPU is the default, not a hidden fallback. WebGPU, cross-origin isolation and a server are unnecessary. Tested in desktop Chrome; Firefox/Safari and physical mobile devices were not tested.

Inputs and reviewed data stay in browser memory and disappear on reload. Only model/runtime downloads leave the device, using GET/HEAD without content bodies. No analytics, uploads, remote actions, credentials, dynamic tool invocation or interpretation of source text as instructions. Browser model/factory caches persist when storage allows; clear site data to remove them. Offline inference is supported on an already-loaded page after a successful cached run, including a fresh worker. Cache-backed online reload avoids model-host requests. Offline navigation/reopening is **not** guaranteed: there is no app-shell service worker. Failed downloads show an actionable error, not demo output.

## Formats

JSON contains model, threshold, every original source record, editable theme assignments/names, original AI reasons/cosines and computed metrics. CSV has one row per original record and quotes/escapes commas, quotes and newlines. Numeric similarity is not a probability or confidence score. Theme explanations refer to the initial suggestion, and are explicitly labeled as such after manual edits. CSV text remains source-faithful; use JSON or import text columns as text when opening untrusted feedback in spreadsheets.

## Limitations and observed quality

Small English short-text encoder, not topic understanding or factual verification. Negation, sarcasm and domain terminology can cause mistakes. On six known-answer pairs in the two six-line fixtures at the 0.45 default, five intended pairs grouped; the night-screen/dark-theme pair (cosine 0.411) remained split. No cross-topic merges occurred in those fixtures. This is a tiny synthetic check, not a general accuracy benchmark. Lowering the threshold can recover missed pairs but may overmerge. All decisions remain reviewable and reversible.

See [VALIDATION.md](VALIDATION.md) and machine-readable browser reports for actual results. Failure injection tests exercise only error handling; successful workflow tests always use real model inference.

## Develop and deploy

`npm install`, `npm run dev`; `npm run predeploy` builds. Required individual deploy script exists but do **not** use it to publish the collection. Publish via the root `/Volumes/ExternalHD/daily_app2` combined workflow. Vite base `/daily-app2/20261106-15/`.

Validation: `node core-test.mjs`; `python3 serve-test.py` serves production `dist` at port 6155, then `node browser-test.cjs`. `TEST_URL` and `REPORT` support running the same suite against the public app. Chrome must be installed for Playwright's Chrome channel.
