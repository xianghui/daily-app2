## Known limits

No crawling, live URL checks, redirect installation, ranking/SEO forecasts, equivalence verification, full-language benchmark, private-document tests or actual mobile-device performance tests. Paths intentionally use a restricted local subset. Every source receives a best-ranked suggestion even if there is no good destination; reviewers should hold such cases. Descriptions exceeding token context are truncated. CSV uses spreadsheet-safe prefixes while JSON preserves exact original strings. Netlify-style rules require platform-specific adaptation and staging checks outside this utility.
