## Local production bundle

- `npm run predeploy` passed with Vite base `/daily-app2/20261110-12/`. Real CPU WASM model execution in Chrome, not mocks for successful runs.
- Packing bench: all 10 proposed links matched intended M/F streams; Print bench: all 10 matched D/T. Each repeats two distinct note texts over five readings: **four unique phrasings total**. Both examples had 0 literal-title hits, 10 human-confirmed proposals, two ready charts, two later readings, one I signal and one MR signal. These easy fixtures are not broad accuracy evidence.
- Negation/unrelated challenge: “No package was weighed…” and an unrelated jazz-concert note both proposed M. AI always supplies a nearest match and cannot establish measurement validity. Both records can be held without loss; mandatory review and exact-unit checks remain essential.
- 1,600 seeded generated cases independently checked mean/range arithmetic, the conventional factors, fixed baseline invariance after later extremes, monitoring flags and import-order invariance. Guards covered duplicate/gapped sequence, missing baseline/monitor, zero range, wrong unit and missing review. No process capability or statistical calibration claim.
- Production-browser checks exercised all 64 notes/8 streams (72 texts in chunks of four), JSON audit reimport, review/edit/undo, hold, duplicate/gapped order, invalid units, current reviewed exports, clipboard, empty/malformed/oversized/invalid inputs, unsupported file formats, cancellation/retry, changed-input staleness, timeout, unsupported workers/WASM and malformed vectors. Fault injection is used **only** for defensive worker/schema/timeout scenarios.

- Real browser 25-reading frozen baseline (26 readings, one later signal), zero-range charts and stale asynchronous file-read guard checked separately. `extra-browser-validation.json` records outcomes.
- Offline: after full caching, disabled networking and created a fresh worker; real inference succeeded in the already-open page. Offline reload/navigation is **not tested or promised**.
- Captured production-startup/inference requests: GET-only assets with no bodies and no synthetic source text in URLs; only documented same-origin/Hugging Face hosts. No model-host traffic before explicit loading. Static asset scan found no credential-pattern matches; source contains no API/provider integration. These checks are not an exhaustive security audit.
