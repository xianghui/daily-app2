# Observed validation — Cart Weave

- React/Vite production `npm run predeploy` passed. No shared credentials or content-upload calls; built text credential-pattern scan clean (not exhaustive security proof). Bundled worker and local runtime use the collection's byte-identical immutable WASM.
- Real browser Chrome / WASM CPU / q8 MiniLM: pantry links `[rice,rice,soap,soap,bags,bags]`; art links `[paint,paint,brush,brush,paper,paper]`; **12/12** known-answer links across two tiny sets. Literal full-title hits are computed independently. No fabricated confidence or universal accuracy claim.
- After mandatory human approvals, pantry estimated goods-first plus delivery **3,800 → 2,690 cents**; art **4,300 → 3,270 cents**. Editing a reviewed pack price changed the selected supplier and total. Baseline uses identical shipping rules. These are estimates for synthetic quotes, not observed savings.
- A further real-AI shipping-threshold fixture chose higher-priced packs to reach a 300-cent free-delivery threshold: goods-first 200 + 500 delivery = **700 cents**, versus 150 + 150 + 0 delivery = **300 cents**. Unknown suppliers, duplicate item IDs, unsupported units, negative thresholds and fractional pack prices were rejected. See `boundary-validation.json`.
- `core-test.mjs`: **1,200 generated independent exhaustive-oracle cases** compared exact minimum landed cost including delivery thresholds, stock and holds; quantity coverage/surplus, bill conservation and baseline bounds passed. Maximum six requirements/24 offers enumerated 4,096 combinations. Empty/malformed/zero/NaN embeddings rejected.
- Production browser suite: real 24-offer chunking, preserved original-input audit reimport with renewed approvals, pending-review guards, unit mismatch, insufficient stock, holds, unconfirmed assumptions, review undo, price edit, export invalidation, clipboard exactness, empty/malformed/oversized data and unsupported formats passed.
- Actual downloaded CSV/JSON/Markdown independently parsed in Python. Every quote survives; current reviewed fields/selected quantities reconcile; commas, quotes, newlines and spreadsheet formula-like notes escaped; 24 original inputs round-trip. CSV is quote-level; full supplier bills and original requirements are in JSON/Markdown.
- Offline: disconnect browser context after successful online model load; terminate worker; create a fresh worker; perform real inference and apply/export another result. Passed only within the already-open cached page. Offline reload/navigation is **not** claimed.
- Fresh-context network abort (Hugging Face), worker download abort, construction failure, malformed vector message, shortened timeout and worker error all produce errors and no fake rows/exports. Network recovery followed by real inference passed. Defensive injected responses are not used to establish AI functionality.
- Cancellation, input change and delayed-file/worker-download guards discard stale work; retry performs real inference. Actual worker with WebAssembly removed returns an actionable requirement error. Default execution is WASM CPU, no WebGPU dependency.
- Network capture from app startup through full production workflow: no model download before explicit invocation; all recorded requests GET without bodies, no supplied source strings in URLs. No external API integration. No orders placed.
- Desktop and 390/320px emulation: no document overflow, working review and download actions, associated labels, visible focus styling and ≥45px form controls. Desktop screenshot visually inspected. Physical phones, non-Chrome browsers and low-memory devices untested.
- Negated and unrelated instruction-like challenge quotes are still nearest-matched; human holds preserve them and block uncovered items. Similarity is not equivalence, grade/size validation or safety certification. See `browser-validation.json` for exact challenge candidates.

Collection/publication checks are recorded separately in `gallery-validation.json`, `gallery-ui-validation.json`, `public-validation.json`, `public-browser-validation.json` and `publication-status.json` when performed. Do not infer successful publication from a branch push.
