# Concordance Bench

**Qualitative coding coordinators → two coders’ informal annotations → reviewed common codes → agreement audit and adjudication queue.** Unlike neighbor-label auditing or grading, this worksheet reconciles two independent single-code views of the SAME units and exposes inter-coder disagreement, missing partners and marginal effects. Nothing contacts participants, changes datasets or adjudicates the truth automatically.

## Workflow / formats

1. Load **Transit feedback** or **Garden feedback**, paste JSON or import `.json`. Supply a `name`, 2–6 `catalog` categories (unique `id`, unique case-insensitive `title`, meaningful `description`) and 1–12 `records` (unique `id`, `unit`, `rater` exactly `A`/`B`, and free-text `text`). IDs/unit IDs ≤40 characters, titles/name ≤80, description/text ≤400. At most one record per unit/rater; identical unit IDs MUST mean the same source assessed independently by the two coders. Missing partners are allowed and reported. This is nominal single-label coding, not ordinal/multi-label reliability.
2. Explicitly **Load AI & reconcile labels**. Real local semantic embeddings map each annotation to a category even when its wording differs from a title. Read the original and every candidate description/cosine score. Correct codes, add reviewer notes, then approve or hold EVERY annotation. Preserve intended independent coder judgments; do not change codes simply to make the score higher.
3. **Apply reviewed agreement audit**. Complete approved pairs contribute to the matrix; held/missing pairs stay in the recovery queue and are excluded from statistics. Disagreements enter the adjudication queue with unit/source IDs and both codes. Review edits invalidate applied results/exports. Undo restores the prior review layer; discard only clears the applied snapshot. Original input is preserved.
4. Download complete JSON/CSV/Markdown or copy Markdown. JSON includes originals, model evidence, every reviewed record, every pair, matrix, marginals, metrics and queue. CSV is one row per original annotation, including holds/missing partners and reviewed notes. It quotes commas, quotes/newlines and prefixes formula-like text with an apostrophe. JSON preserves exact source strings. Markdown is a human-readable matrix/queue plus all records, not a machine interchange format. JSON reimport restores originals ONLY and requires fresh inference/review. No external actions.

## Real AI, static runtime and privacy

- Model: [Xenova/all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2), Apache-2.0, q8 ONNX, normalized mean-pooled 384-dimensional embeddings. AI performs semantic codebook retrieval only; no hard-coded labels/responses or keyword fallback. Cosine similarity is not confidence, truth or equivalence. Quantities, matrix/pair validation, counts, kappa and exports are deterministic.
- React + Vite, base `/daily-app2/20261111-21/`; Transformers.js 4.3.2 / ONNX Runtime Web, single-thread WASM CPU. No WebGPU needed, no backend, no API keys/paid mandatory services/remote provider. Worker/runtime factory are local same-origin production assets.
- First load requires internet: ~23 MB model/config/tokenizer from huggingface.co / hf.co and CDN plus 26,861,777-byte same-origin WASM; allow ~50 MB transfer and several hundred MB working memory. Model-host revisions are unpinned; upstream changes can affect downloads/behavior. Before explicit invocation no model-host download occurs. Model file GETs download weights; source annotations are sent only to a local browser worker, not off-device. No telemetry, storage of user content or server inference. Only synthetic fixtures are committed. Imported instructions have no tool authority.
- Reuses immutable identical WASM from `/daily-app2/20261107-2/assets/ort-wasm-simd-threaded.asyncify-CxOG5pUO.wasm`; preserve this older asset when assembling the collection. Hashes recorded in `runtime-assets.json`.
- Current desktop Chrome with WebAssembly SIMD/module workers/Cache API tested. Physical phones, screen readers and other browsers unverified. Layouts checked at 1440/390/320 px. No oversized LLM or WebGPU requirement.
- Worker source, factory and WASM use Cache API; model assets use Transformers.js caching. After successful online inference, a fresh worker in an **already-open warmed page** completed actual inference with all network disabled. Offline reload/navigation/app-shell startup is NOT claimed. Private browsing/cache eviction can require downloads again. Content remains in page memory and disappears on reload unless exported.

## Limits and defensive behavior

Original JSON ≤18,000 characters; audit envelope/file ≤1 MB; 2–6 categories + 1–12 annotations (≤18 text embeddings). Four-text chunks; 256-token context, so pathological tokenization can truncate a 400-character field. Reviewer notes ≤400 characters. Counts/schema, finite near-unit 384-vectors, unique IDs/titles and unit/rater uniqueness are validated. Empty, malformed, oversized and unsupported imports, unavailable workers/WebAssembly, download/runtime errors, malformed vectors and 180-second timeout give actionable errors and no fabricated suggestions. Cancel/input edits terminate workers; run tokens protect delayed worker downloads/messages and delayed file reads. Retry starts a fresh worker. All annotations must be explicitly approved/held before applying.

## Deterministic agreement / baseline

Let N be complete approved pairs, O the diagonal count, A_i/B_i coder category counts. Observed agreement is O/N. Expected agreement is Σ(A_i B_i)/N²; nominal Cohen kappa is `(O*N − ΣA_iB_i)/(N² − ΣA_iB_i)`. With no included pairs, observed/expected/kappa are null. When expected agreement is exactly 1, kappa is null/undefined, NOT zero or perfect reliability. Negative kappa is valid. Matrix rows are A, columns B; each included unit contributes exactly once. Missing takes precedence over held for a unit without a partner; original row decisions remain visible.

Baseline: trim/case-insensitive EXACT category-title lookup (unresolved otherwise), computed on the same annotations. The UI shows resolved count and AI/exact matches to current approved human codes; these are review-agreement counts, not independently measured accuracy. The fixture report separately compares real predictions with synthetic intended codes. No elapsed-time/savings or confidence claims. No forced universal improvement claim; an exact label is often best handled without AI.

Kappa is descriptive, not truth, accuracy, causal evidence, a release threshold, statistical significance, ordinal weighting or general reliability certification. Tiny samples, skewed marginals, related units and selective exclusion can mislead; inspect paired coverage, full marginals and every excluded/disagreeing unit. No confidence interval is provided. The model fails on negation and unrelated input can be forced to an arbitrary category; mandatory human review/hold is essential. No automatic adjudication or content generation.
