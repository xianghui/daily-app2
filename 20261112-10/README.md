# Trace Orchard

Private batch-link reconciliation and downstream investigation worksheet for small workshop traceability coordinators. Real semantic inference resolves informal source-batch descriptions; a reviewed directed graph reveals indirect recipients that a one-hop list misses. No notices, account changes, inventory posting, stock disposal or remote content processing.

## Workflow
1. Paste/import JSON or load **Bakery trace** / **Lamp workshop**, both synthetic. `catalog` contains batch `id,title,description`; `records` contains `id,text,toLot,qty`. Text describes the **source** batch; `toLot` is the destination. `focusLot` is the batch under investigation. One source unit per batch; quantities are audit evidence only, not converted, balanced or totaled across products. Include every relevant batch/transfer; omissions cannot be detected.
2. Explicitly click **Load AI & reconcile reports**. Local MiniLM embeds the supplied batch descriptions and source notes, ranks cosine similarity and proposes source IDs. No regex, canned answer or fake fallback. Imported instructions remain data, not commands. The model does NOT authenticate lot IDs, detect contamination, extract destinations, verify quantities or know which lots are affected.
3. Review **every** source ID, destination ID and quantity. Correct suggestions, approve verified links or hold ambiguity, add notes and undo edits. Verify near-identical lots against primary records: semantic similarity is not identity. Originals remain unchanged. Source JSON edits cancel/invalidate the run; review edits invalidate applied exports.
4. Apply. Any hold blocks **all** path results, because an unknown edge might extend impact. Approved directed cycles or self-transfers block release, including disconnected cycles; represent rework with distinct batch IDs. For an entirely reviewed acyclic graph, breadth-first traversal returns all reachable batches and one shortest evidence-linked path per batch. Every catalog batch appears, including those not reached. Compare all downstream batches with the focus-plus-immediate-recipient baseline. These are computed supplied-graph counts, not measured recall completeness or accuracy.
5. Export complete JSON, transfer-audit CSV or Markdown checklist, or copy Markdown. Held audits remain exportable but contain no released checklist. Exports reflect current reviewed links. JSON audit reimport restores **original inputs only**, requiring new inference and renewed review. CSV quotes multiline content and protects formula-like text. No external actions happen.

**Interpretation:** Reached means isolate/investigate under your procedures, not proven contamination. Not reached is **not proof of safety**. Missing links, omitted batches, incorrect identities and unrecorded rework/returns can change the whole result. Quantity does not constrain graph traversal: any approved positive transfer propagates investigation. This worksheet is not a certified recall system or substitute for primary records, regulatory procedures or qualified decisions. One shortest path is evidence, not an exhaustive list of all paths.

## Real AI and runtime
- Model: [`Xenova/all-MiniLM-L6-v2`](https://huggingface.co/Xenova/all-MiniLM-L6-v2), Apache-2.0, quantized q8 ONNX, approximately 23 MB including tokenizer/config. English semantic feature extraction, mean pooling, normalized 384-dimensional embeddings. Not generative; unrelated text still gets a nearest candidate; negation/near-identical batches can mislink. Mandatory human review has no fabricated confidence percentages.
- `@huggingface/transformers` 4.3.2 (Apache-2.0), ONNX Runtime Web (MIT), WASM CPU. Four texts per inference batch, 256-token context with truncation; long/wordy descriptions may lose context. Finite normalized vector shape/count validated before ranking.
- Approximately **50 MB first download**: ~23 MB model/tokenizer from huggingface.co / hf.co and model CDN; ~27 MB WASM from this same-origin collection. App code, worker and WASM factory are locally hosted. Byte-identical immutable shared WASM: `../20261107-2/assets/ort-wasm-simd-threaded.asyncify-CxOG5pUO.wasm`. Preserve that older app asset. SHA-256 recorded in `asset-privacy-validation.json`.
- Requires module workers and WebAssembly SIMD, with several hundred MB free RAM recommended. CPU path does not need WebGPU. Desktop Chrome tested; physical phones, low-memory devices and other browsers untested. No promise of universal phone performance.

## Privacy, download, offline and failures
No credentials, API keys, backend, analytics, optional remote AI or app-initiated user-data persistence. Notes remain in browser memory. User content is not sent to model hosts; public weights are downloaded. Cache API stores public worker/runtime files; Transformers.js caches model files. Nothing is downloaded from a model host before explicit loading. Progress, cancellation and retry are exposed. Cancellation terminates workers; run IDs protect delayed worker fetches, imported-file reads and results. 180-second timeout, network/worker/runtime errors and malformed embeddings show actionable errors, never fabricated outputs. Model URLs are unpinned upstream public revisions; caches can become stale, change or be evicted. Private browsing may disable caching.

After online inference, **fresh-worker offline inference inside an already-open warmed page was tested**. Offline reload/navigation is not supported or promised. All required runtime files, not just weights, are explicitly cached for that scope. Cancellation may leave downloaded public assets cached, never note content.

## Bounds/formats
2–8 batch profiles; 1–24 transfer records; unique IDs ≤40 characters; titles ≤80; descriptions/notes ≤400; positive integer `qty` ≤1,000,000; originals ≤18,000 JSON characters; audit/file import ≤1 MB. IDs are exact case-sensitive references. Input JSON only; CSV/PDF/photo imports unsupported. Export JSON/CSV/Markdown. Missing source mappings stay pending until reviewed; holds do not silently disappear.

## Development/publishing
`npm install`, `npm run dev`, `npm run predeploy`. React + Vite; base `/daily-app2/20261112-10/`. Required individual `predeploy` and `deploy` scripts are retained; publish only through the ROOT collection workflow, never individual deploy. Shared WASM must remain available.
