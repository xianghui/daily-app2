- `npm run predeploy`: passed. Real headless installed Chrome, GPU disabled; production Vite base and immutable same-origin worker/factory/WASM, not development-server imports.
- Real no-key WASM inference: **10/10 intended links** across two materially different tiny synthetic fixtures. Notched garden: gate/compost/fountain/shed/greenhouse/oak; 18 m² polygon vs 30 m² bounding rectangle; 20 vs 33 50-L bags with 5-cm depth and 10% waste. Festival trapezoid: stage/cafe/art/bike; 12 vs 15 m²; 6 vs 8 40-L bags at 2 cm, no waste. See browser-validation.json for actual cosine evidence and results; no general accuracy guarantee.
- Real semantic-sensitivity check: swapping only two boundary-note descriptions changed MiniLM links from compost/fountain to fountain/compost and changed the downstream result from a released 18-m² outline to a blocked self-crossing outline. No mocked model or deterministic fallback; see semantic-change-validation.json.
- **1,200 independent sum-of-rectangles area/perimeter oracle cases**, each translated, rotated, scaled, reversed and cyclically shifted. Crossings/touches/degeneracy rejected. Mandatory approvals, full one-to-one vertex mapping and unique traversal permutation enforced. Schema/finite normalized vector validation and whole-bag integer-boundary checks passed.
- Review/edit link and traversal; duplicate/crossed outline blocks; hold/reject/undo; original preservation; any edit invalidates exports; multiline formula-like note survives JSON/CSV; clipboard and audit reimport renew inference/approvals.
- Maximum 12-landmark/12-note batch: 24 texts in six real model chunks. Deliberately repetitive descriptions are ambiguous; links were manually corrected rather than counting them as accurate AI. Every record and final multiline note survives exports/reimport.
- All-network-off fresh-worker inference passed in a warmed already-open page. Offline reload/navigation not tested or promised. Privacy trace from production startup through inference observed only GET/HEAD downloads, no request bodies/source text in URLs and no model-host requests before explicit loading. Persisted URL audit omits CDN query tokens. Secret-pattern scan and integration inspection supplement this, not a universal security proof.
- Empty/null/invalid/oversized JSON, invalid depth/bag/waste/coordinates/order/text/record counts, unsupported file and >2-MB envelope blocked. Cancel/retry and changed-input invalidation passed.
- Fault-injected host failure with real retry; absent WebAssembly, worker download/construction/error, malformed vectors/envelope and accelerated 180-second timeout all fail without fake output. Cold model-request cancellation followed by real retry passed. Delayed file import and late old-worker result cannot overwrite newer input/result (latter race deliberately fault-injected).
- Actual browser-downloaded JSON/CSV/Markdown/outline CSV independently reopened with Python csv/json parsers: all originals, coordinates and reviewed positions retained; quoted commas/newlines, formula-safe textual notes and maximum records preserved.
- Desktop 1440px and narrow 390/320px browser viewports passed no horizontal overflow, labelled controls, visible focus and ≥44px buttons. Normal-viewport overview/review/results screenshots inspected. Native select labels are compact; complete selected descriptions are shown separately. Physical phones, alternate browsers, screen-reader operation and low-memory hardware remain untested.
