# Link Commons — observed validation

## Production workflow, CPU browser inference
- React + Vite `npm run predeploy` passed with actual `/daily-app2/20261119-5/` base. No server-only inference path or API credentials.
- Real Chrome with GPU disabled ran local WASM MiniLM inference on both materially different synthetic examples, matching **5/5** intended route identities (2 archive/video transfers and 3 overlapping-path studio transfers). This tiny easy fixture set is not an accuracy estimate.
- First reviewed plan: rates **2, 8 Mbps**, total 10, vs static-share baseline **2, 5**, total 7. Link capacity 10 Mbps is respected.
- Second plan: **7, 1, 5 Mbps**, total 13, vs static **4, 1, 4**, total 9. Studio trunk load is 12/12, remote link 6/6. Multi-link transfer consumes its rate on both links; sum of flow rates is not sum of link loads. These are deterministic planning values, not measured speed improvements.
- Unrelated/negated instruction-like text still retrieves a nearest route, held explicitly to block the plan. AI does not validate intent/permission or reliably abstain; no instruction execution/content upload.
- Core known-answer allocations and **2,000 generated** random path/weight/demand scenarios pass demand/capacity constraints, flow conservation, baseline dominance, step limits and a weighted max-min bottleneck certificate for every unsatisfied flow. Vector count/dimension/finiteness/normalization, invalid capacities/paths/weights and holds validated.
- Maximum eight links/eight routes/24 transfers = 32 neural texts in four-text chunks runs real inference. All 24 original records survive reviewed JSON/CSV and audit reimport; reimport resets approvals and restores originals only.
- Pending/hold blocking, review route/demand/weight edits, approval reset, undo, multiline notes, invalidation of applied exports, current clipboard and downloaded JSON/CSV/Markdown checked. Independent Python parsing verifies originals, current edited fields/rates, all rows, quotes/commas, multiline text and formula protection. All artifacts are synthetic.
- Real inference from a newly created worker passes with browser offline after the initial online run. Scope is the same open warmed page only; offline reload/navigation, cache eviction, private mode and first-run offline are not claimed.
- Invalid/empty/oversized/duplicate inputs, unknown links, unsupported formats and numeric limits checked. Real cancellation/retry and changed-source invalidation pass. Defensive delayed old-worker result cannot overwrite a newer completed run; delayed file read cannot overwrite newer source.
- Eight defensive injection cases produce errors and no fake recommendations/exports: blocked model network (then real-model retry succeeds), missing WebAssembly, blocked worker download, unsupported Worker, malformed vectors, null envelope, accelerated timeout branch, worker error. Mocking is used only for defensive branches, never the working-AI tests.
- Production network inspection from page startup through inference finds no model download before explicit invocation; requests are GET without bodies, no fixture text in URLs and only documented same-origin/Hugging Face/CDN paths. Reports strip signed query values. Source/data-flow inspection plus built-text credential-pattern scan finds no provider integration or embedded secrets.
- 1440px desktop and 390/320px phone viewports: no horizontal overflow, input/review/result screenshots inspected, all forms labeled, visible keyboard focus and ≥44px buttons. Physical phones, other browser engines, screen-reader speech and minimum-memory devices untested.
