# Search Lantern

A no-key local-AI rank-fusion worksheet for resource curators combining ranked search results or expert reading lists. Neural semantic matching proposes partial one-to-one identities across paraphrased descriptions. Humans verify the same work/edition, correct links or hold B results, then apply transparent **reciprocal rank fusion (RRF)** to produce a bounded reading shortlist. No searches, page fetching, catalog edits, messages or uploads occur. This is not a generic chat wrapper or population estimator.

## Workflow / formats

1. Choose **Community archive** or **Digital resource audit** (synthetic), paste JSON or import originals/audit `.json` up to 2 MB. Source: `context`, `minSimilarity`, `rankConstant`, `shortlistSize`, `first[{id,text}]` (ranked list A), `records[{id,text}]` (ranked list B). Array order supplies original ordinal rank, beginning at 1. Each list contains 2–8 unique resources. IDs are unique within each list, not required to match across lists. Include identity context, not only generic topics. Context documents the goal; only descriptions enter the embedding model.
2. Set `minSimilarity` 0–1 (examples: 0.45, not calibrated confidence), `rankConstant` 1–100 (examples: 60), `shortlistSize` 1–16 (examples: 3). **Load AI & reconcile** explicitly loads the real model. Download and four-text inference progress appear; cancellation terminates the worker and retry starts anew. Timeout: 180 seconds. Neural embeddings materially drive identity scores. Deterministic exact partial assignment maximizes total positive `cosine − minSimilarity`, subject to at most one link per A/B resource. A below/equal-threshold candidate need not match. Equal objective ties retain the first stable explored solution, favoring unmatched branches first.
3. Review every B result, inspect all source descriptions/cosines, select a corrected A identity or **No overlap**, add multiline notes and approve or hold. Similarity is not confidence or identity/edition verification. Two approved B results cannot claim the same A resource. Link changes reset approval. Undo restores up to 100 review snapshots. All originals and source ranks remain untouched.
4. **Apply reviewed reconciliation** computes RRF per reviewed candidate: `1/(k + rankA) + 1/(k + rankB)`, skipping absent lists. k is rankConstant. Rank descending, with original candidate order breaking equal scores; shortlist the requested count or all available candidates if fewer. A candidates retain source order as tie-break priority, followed by approved B-only results. Held B resources remain in the audit but are excluded from fusion. Other source ranks are **not renumbered** when results are held. A resource that might correspond to an unresolved held B result still remains its own candidate.
5. Inspect the reading queue and full candidate/deferred/held manifest. Compare with a simple first-list-then-approved-B-only concatenation baseline, using the same reviewed groups and same selected count. Cross-list consensus counts mean a reviewed item appears in both supplied lists; RRF score sums are objective values, not accuracy, probabilities, source quality, reading value or measured time savings. Correlated lists may amplify the same bias. All input/review/undo changes invalidate the applied export snapshot.
6. Download complete JSON audit, all-original **CSV**, **Manifest CSV** or **Markdown**, or copy the worksheet. JSON preserves both originals, every proposal/evidence/review, holds, scores, baseline and shortlist. All-record CSV preserves each A/B original with its original rank, reviewed link and note. Manifest CSV has every candidate/hold, both source ranks, fused rank, score and shortlist flag; held score/rank are blank. Markdown contains the ranked queue plus every original and hold. Matched B text survives JSON/all-record CSV/Markdown; the manifest uses A text with both source IDs. JSON reimport restores **originals only**, requiring fresh inference and review.

CSV quotes commas/newlines/quotes and prefixes text beginning `= + - @ tab CR` with an apostrophe against spreadsheet interpretation. JSON is the lossless audit; CSV formula hardening is intentional. No actual resource files are downloaded or merged.

## Privacy / downloads / offline

No credentials, analytics, optional provider or remote inference. Only explicit model loading downloads public model/tokenizer/config files from Hugging Face/CDN; worker/factory/WASM are same-origin collection assets. Descriptions, embeddings, source order and reviews remain in browser memory. Download hosts receive normal network metadata, not resource text. Production request checks found only GET/HEAD, no bodies and no source text in URLs. Imported instructions remain inert data and cannot authorize tools or request secrets. Only synthetic fixtures/artifacts are committed.

Public worker source uses `search-lantern-worker-v1` Cache API; factory/WASM use `circuit-cove-runtime-v1`; Transformers.js caches public model files. No inventory content is cached. After a successful online run, **fresh-worker real inference works with all network disabled in the already-open production page**. Offline reload/navigation/app-shell startup is not promised. Eviction/disabled caching needs internet. Reload clears unsaved inputs/reviews; exports remain user-controlled files.

## Bounds / limitations

Source 1–50,000 characters, import envelope ≤2 MB, context/descriptions 1–300 characters, notes ≤1,000. Each list: 2–8 resources. IDs 1–40 ASCII alphanumeric/underscore/hyphen, unique within list. k 1–100 and shortlist 1–16 whole numbers; threshold finite 0–1. Run IDs guard file reads, worker-source fetches and messages. Cancel/input changes terminate workers. Malformed output, timeouts, worker/network/WASM failures do not release fake suggestions.

A similar topic may be a distinct resource, edition or copy. The model cannot verify URLs, author identity, publication quality, availability, truth or actual edition. Resolve uncertainty manually or hold B results. Within-list duplicates cannot be inferred away: supply unique resources or fix originals. RRF treats each list as one equal ordinal source; there are no learned source weights, independent-quality guarantees or calibrated scores. It may rank a high single-list item above weak consensus depending on k and ranks. Changing k is a preference choice, not a fitted relevance estimate. The baseline can be preferable to a reader; no universal superiority is claimed. No summaries, citations or missing resources are invented.
