## Local model and workflow

- Both Library access and Workshop access ran real MiniLM inference. All **12/12 expected question links** matched. The values and gates were not generated by the model. `browser-validation.json` records actual cosine evidence and network paths.
- Each three-person questionnaire retained 6 original records and 9 person/question cells: **4 active answers, 2 confirmed missing, 1 intentional skip, 1 unexpected off-path answer, 1 gate-blocked cell**. The naive rectangular baseline counted 3 blanks. Difference is a conditional audit distinction, not observed time saved.
- Swapping two informal question labels changed neural links and therefore the downstream skip/missing audit. This validates semantic sensitivity, not just model loading.
- 1,500 independently generated acyclic gating cases matched a separate ancestor-chain oracle, including shuffled question order. Invalid cycles/unknown gates, vectors and review schemas are rejected. The oracle independently computes eligibility before comparing states.
- Maximum: **8 questions + 96 records = 104 real embeddings in 26 chunks**, 12 people, 96 preserved cells/records. Complete reviewed JSON/CSV/Cells CSV reimported successfully; imports deliberately restore originals, never approvals.
- Actual downloads parsed with Python csv/json. All source rows, binary zero/no values, blank missing values, every roster member and all skipped/blocked cells survived. Multiline comma/quote/formula-like notes survived JSON, safely escaped CSV and clipboard. Markdown preserved every source note.
- A real-inference threshold of 1 left every link unassigned; holding all records could not activate gates. Editing an explicit equality condition and rerunning changed the deterministic path audit as expected (`rule-threshold-validation.json`).
- Mandatory review blocks application; mapping/value edits reset approval; undo, hold and review-note editing work. Duplicate approved cells, out-of-range answers, invalid source/gates/format/oversize imports are blocked. Editing reviews clears exports until reapplied.
- Browser network audit: only GET/HEAD downloads, no request bodies or source text in URLs, no model host traffic before explicit loading. Built-text credential pattern scan matched zero; manually inspected integration has no credentials, analytics or optional remote inference.
- After successful loading, browser networking disabled and the existing worker terminated: a **fresh worker** completed real inference in the already-open warmed page. Offline reload/navigation and physical phone inference were not tested or promised.
- Error-only fault injection: model network abort then **real retry**, unavailable WebAssembly, worker-construction/download/runtime failures, malformed vectors/envelope, timeout. All left exports disabled with no fabricated output. These mocks are not used for the successful model checks.
- Cold model download cancellation, late source fetch, delayed file import and a deliberately non-terminating old worker result were checked. Cancelled/older runs cannot replace newer inputs/results. Real retry succeeds.
- 1440/390/320px viewports: no horizontal overflow; input labels, visible focus and ≥44px buttons checked. Normal viewport input/review/results screenshots visually inspected. Physical touch, screen readers and other browsers remain unverified.

## Limitations

MiniLM topical similarity is not negation/entailment, participant verification, survey truth or policy interpretation. Similar labels may need manual corrections; tiny successful fixtures do not establish universal accuracy. Supplied explicit gates are not inferred or repaired by AI. Blocked gates are unresolved, not intentional skips; held answers can create apparent gaps. A skipped ancestor overrides answers on its inactive branch. Structural completeness does not grant permission or imply that anyone should be contacted. Only binary answers and a single equality gate per question are supported.
