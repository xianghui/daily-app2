Injected faults are defensive tests only, not evidence of successful AI. Delayed file reads and worker fetches could not overwrite new input; old worker errors could not overwrite a newer real run. See defensive/cold-cancel/async-race/newer-run reports. Final production scope checks also rejected extra metadata at all three schema levels, blocked duplicate non-reentrant mutexes without mutating originals and recovered after identity correction (`scope-validation.json`).

Captured network requests from production startup through inference: no model-host downloads until explicit loading; all requests were GET with no body, no synthetic user text in URLs. Reports persist host/path/query-key names only, not signed CDN query values. No optional provider/upload route exists. Built text-asset credential-pattern scan plus integration inspection passed; a pattern scan alone is not an exhaustive security proof. Shared worker, factory and WASM hashes match source and assembled build.

Actual offline claim tested by disabling all browser network after a warmed run, terminating the previous worker and running a fresh worker successfully. **Only already-open warmed-page inference is promised**, not cold offline navigation or indefinite cache retention.
