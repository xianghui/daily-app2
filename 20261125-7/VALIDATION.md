## Limitations

English short-context embedding retrieval is not a schema identity guarantee. Missing descriptions, near-identical contracts, negation and unrelated instructions can misroute; imported strings have no authority. Required keys check presence only, not field type/value/business rules. Fractional binary rounding below 2^53−1 is not detected. Exact raw strings are retained; reserializing convenience values does not preserve formatting, escape spellings or key order. Direct textarea editing follows browser newline behavior; use escaped raw strings in source JSON when CR/LF distinctions matter. This utility does not inspect already-parsed upstream data for losses that already occurred. It never performs endpoint calls or imports. Cache eviction/private mode may require downloads again. No phone-speed, accuracy or time-saving guarantees.
