# Coatfolio Desk

A local-AI coating-quantity worksheet for workshop estimators. Informal maintenance handoffs rarely use exact finish-profile names. Real MiniLM sentence embeddings retrieve supplied profiles from meaning; humans verify them before deterministic film-volume, loss and shared-pack calculations. This is not a product selector, mixing recipe, generic chat interface or automated ordering system.

## Workflow and formats

1. Try **Room refresh** or **Workshop finishes**, paste source JSON, or import `.json` (≤1 MB). Source limit: 30,000 characters, title ≤100, 2–8 profiles, 1–12 jobs; unique simple IDs ≤24 characters; profile descriptions and job notes ≤200 characters.
2. Explicitly **Load AI & match profiles**. Initial internet download is approximately 50 MB (~23 MB weights and ~27 MB runtime); progress shows file download and four-text inference batches. Cancel terminates the worker; load retries. Timeout: 180 seconds.
3. Review original notes and ranked source descriptions. Correct profile links and every numeric assumption; approve or hold each job. Profile/numeric edits reset approval. Edit multiline reviewer notes; undo up to 30 changes. All shared copies of a profile's reviewed parameters must agree.
4. **Apply reviewed worksheet**. All-job volume metrics include holds; shared purchasing pools include approved jobs only. Held jobs or pack-cap excess block Pack CSV, not complete audits. Later edits invalidate exports. Originals never change.
5. Download JSON, Audit CSV, Markdown or Pack CSV, or copy the current Markdown handoff. JSON `coatfolio-v1` preserves originals, every reviewed job, similarity evidence, calculated volume components and shared pools. Reimport restores originals only, requiring fresh AI/review. Audit CSV retains every job including holds. Pack CSV has one row per profile and exact unrounded demand, stock, pack size, new packs and ending balance.

CSV uses quoted RFC-style cells and CRLF, preserving embedded quotes, commas and newlines. Formula-leading text (`= + - @ tab CR`) is apostrophe-prefixed; numeric fields retain numeric values. JSON preserves exact reviewer text. No equipment commands or external actions.

### Numeric contract

- Profiles: integer volume solids and transfer efficiency 1–100%; pack size 0.1–100 L in 0.1 steps; usable stock 0–10,000 L in 0.01 steps; maximum new packs 0–10,000 integer.
- Jobs: measured net area 0.01–10,000 m² in 0.01 steps; dry film per coat 1–1,000 µm integer; 1–10 coats integer.
- Empty, malformed, unsupported and oversized files are blocked. Invalid review fields cannot be applied. Text accepts proper Unicode and normal newlines/tabs, not unpaired surrogates or other control characters.

## Real AI, source, runtime and privacy

Model: [Xenova/all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2), Apache-2.0, q8. Transformers.js 4.3.2 (Apache-2.0), ONNX Runtime Web (MIT), WASM CPU; normalized mean-pooled 384-dimensional embeddings. Cosine ranks each job against profile descriptions. Vector count, shape, finite values and normalization are validated. Similarity is **not confidence**. No numeric specifications are generated by AI. Numeric validation, formulas, grouping, rounding, release guards and exports are deterministic.

No API key, paid service, account, optional provider integration or server inference. User content stays in the local browser worker; only runtime/model files are downloaded by GET from this site, Hugging Face and its CDN. Text cannot grant authority, request credentials or trigger tools. No analytics, remote upload or automatic saved workspace. Export before closing the tab.

Requires a current browser supporting module workers and WebAssembly SIMD, with adequate memory. No WebGPU required. Tested in installed desktop Chrome with GPU disabled; physical phones, other browsers and low-memory devices untested. Responsive phone layouts are browser emulations, not device performance claims.

Shared immutable same-origin assets (preserve the originating apps):

- `/daily-app2/20261115-6/runtime/ort-wasm-simd-threaded.asyncify.mjs`

Worker source, factory and WASM use explicit Cache API caching; model files use the runtime cache. Cache storage may fail/be evicted. Fresh-worker inference with all network blocked **in an already loaded page after an online run** was tested. Offline reload/app-shell startup is not supported or claimed. Worker uses four-text batches; a passed `max_length` is ignored by this feature-extraction pipeline, so enforce ≤200-character texts and retain the tokenizer's own model limit, rather than promise a smaller token cap.

## Deterministic method and comparisons

Dry solids L = area m² × dry film µm × coats ÷ 1000. Retained wet L = dry solids L ÷ volume-solids fraction. Required supply L = retained wet L ÷ transfer-efficiency fraction. Wet film µm per coat = dry µm ÷ solids fraction. Transfer loss = supplied minus retained wet volume.

Baseline treats dry solids volume as supplied liquid, ignoring solids and transfer losses. Its shortfall is the difference from the reviewed estimate, not measured consumption or accuracy. Approved jobs pool by finish ID. New packs = ceiling(max(0, pooled requirement − stock) ÷ pack size). Stock is counted once per pool. Ending balance is checked nonnegative (floating tolerance 1e-8 L). A 1e-10 pack-count tolerance avoids spurious rounding at binary-float boundaries. Calculations use JavaScript doubles; display rounds to three decimals, export retains full precision.

Pooling comparison computes separate whole-pack counts versus shared counts **with zero stock in both scenarios**; it is not an allocation of the same stock to each job. Pack caps are hard release constraints. No invented percentage improvements, elapsed time or universal accuracy.

## Limitations

Similarity does not verify substrate suitability, safety, coating chemistry or a datasheet. Negation challenge selected the unsuitable steel profile: mandatory review is intentional. Synthetic profile numbers are illustrative, not real product advice. English-first and always returns a nearest profile, even for unrelated text; hold it when uncertain.

Verify actual net surface areas, volume solids, film thickness and application loss estimates. No thinning, density/mass-solids conversion, mixed-component ratios, pot life, recoat timing, porous uptake or application-specific variability. Do not double-count the same loss in solids and transfer assumptions. Stock pools must be truly separate by profile; representing one physical stock twice will overstate availability. No purchasing, equipment controls or remote actions.
